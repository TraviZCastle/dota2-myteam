# Dota 2 MyTeam

五位传奇，一位名帅。可离线运行的 Dota 2 历史选秀与生涯游戏。

在线游玩：[dota2-myteam.vercel.app](https://dota2-myteam.vercel.app/)

## 运行

```sh
cd /Users/test/Documents/ForFun/Dota2MyTeam
python3 -m http.server 8930 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8930/>。也可直接打开 `index.html`；不同协议、端口和浏览器的存档互不共享。无需安装依赖，没有运行时 API 请求，没有选手头像。

## 当前版本

- 首页采用 Dota 2 官网英雄群像与官方标识，提供已有生涯的继续入口、历史卡库概览、可查看真实资料的跨时代示例阵容，以及三步玩法说明。官方素材本地保存在 `assets/brand/`，来源和 SHA-256 见 `assets/brand/sources.json`；页脚注明非盈利个人项目及 Valve 素材归属。
- TI1 / 2011 至 TI15 / 2026：15 届、120 个历史八强战队池。选秀、换人和图鉴只收录 TI2—TI15 的 112 个战队池、560 张选手卡，以及 48 张 TI10—TI15 八强代表教练卡。2020 年无赛事。
- 五名选手分别占 1—5 号位；之后进入必选教练轮，只抽年份，展示TI10—TI15 当届八强的八位代表教练，直接选一人。每队仅保留一张教练卡，多人教练组不额外占席。跨年份、改名和选手/教练身份共享人物标识，不能一人占两席。
- 选手轮只提供一个重抽按钮，一次同时更换年份和战队，保证两项都与当前不同，且同一轮内不再抽到此前出现过的战队（跨年份按同一战队识别）；选定选手进入下一轮才重置战队记录。刷新、取消换人或切换教练席都保留本轮记录；旧存档没有记录时从当前显示的战队开始记录。初始 3 次，选秀和休赛期换人共用；每届首次进入换人时再赠送 1 次，未用完可累计，刷新、取消再进入、切换位置均不重复发放，生涯结束不再赠送。旧存档按两类重抽已消耗次数的总和折算剩余额度，最低为 0，不重置生涯。教练轮有独立的一次年份重抽，不抽战队，不消耗选手额度。教练年份固定为 2021—2026，每届八张；同一人物与已有选手冲突时仍禁选。
- 抽签使用多个候选项连续滚动并逐渐减速，选手抽签 1 秒、教练抽签 0.8 秒。选手的年份与战队在同一个框内成对滚动，每一帧都来自真实的当届战队池，整体减速并同时揭晓两项；教练只滚年份。名单、人数、名次等结果信息在结束前隐藏。结果先保存，跳过动画不重抽；系统启用减少动态效果时使用 150 毫秒等待提示。
- 手机端采用底部导航，选秀阵容默认收起、可随时展开；选人后自动回到下一轮抽签，换人时保留全部席位。按钮扩大触控区域，备战与图鉴在窄屏使用单列卡片；战报以英雄头像、中文名、选手和定位逐行展示，弹窗支持独立滚动、固定关闭按钮和安全区留白。
- 560 张 TI2—TI2026 选手卡接入 OpenDota 逐场统计和真实英雄使用次数。TI1 的 40 名选手仅保留为赛事历史对手，从选秀、换人和图鉴中移除，不填假数值；其他届次的同名选手卡仍可选择。
- 组队后只需确认阵容，固定从 TI1（2011）出征，不再提供风格或英雄选择。战队风格自动跟随所选教练，换教练、进入下一届、恢复旧存档均同步更新；历史结果不改写。自动 BP 参考选手与教练的历史英雄使用及战术；选手 Top 3 英雄头像、中文名、局数和资料详情保留。旧存档的手动偏好移除，阵容、生涯和已完成战报保留。
- 选手 Top 3 常用英雄展示英雄头像、中文名与使用局数，覆盖选秀、备战和图鉴；详情也保留英雄头像。选手本人不使用头像。英雄图片缓存于 `assets/heroes/`，来源记录在 `sources.json`，可用 `python3 scripts/fetch-assets.py` 补齐。
- 执教生涯统计按同一人物的全部已收录 TI 八强教练条目汇总，按历史战队池去重，仅计教练身份。局数和胜率来自该队该届可用比赛样本，胜率为总胜场 ÷ 总局数，不平均各届百分比；没有逐场数据的记录只参与名次统计。最高成绩取最好名次并统计次数，如“冠军 × 2”“亚军 × 2”；详情可核对逐届记录和来源。不包含选手经历、未收录 TI 战队或其他赛事。
- 教练参考执教战队的历史英雄使用，影响针对性禁用、选英雄和战术适配。教练卡不再展示常用英雄，改为擅长风格、历史胜率、历史局数、最高成绩及次数；风格仍是当届执教样本生成的游戏设定。
- 新生涯固定从 TI1（2011）起步，移除赛事年份选择；按赛事顺序征战全部 15 届，直到 TI15（2026）结束；停在 TI10 的现有存档刷新后可继续进入 TI11。每届结束可随机抽签换一名选手或教练，下一届生效。换教练从阵容的教练席进入，沿用TI10—TI15 年份与八强直选规则，该次换教练可独立重抽年份一次；取消、切换选手位置、刷新均保留年份及已消耗次数。已完成赛果保留当时六席。
- 自定义战队替代当届八强名单末队，与另外七队直接进行双败淘汰赛。按历史名次排序，并列沿用卡库顺序，固定替换最后一队；首轮 1–8、4–5、2–7、3–6，全部从胜者组开打，普通轮 BO3、决赛 BO5（不重置），共 14 场系列赛。提供最终名次、完整对阵和逐局战报，不打循环赛。
- 结果页以带晋级连线的胜者组 / 败者组对阵树为主体，顶部独立展示当届冠军与冠军盾；最终排名折叠显示。全部 14 场系列赛都可点击，按局切换双方英雄头像、中文名、位置、选手、禁用、击杀与防御塔。手机端对阵图独立横向滚动，战报按行显示。旧赛果不补造未保存的对手逐局记录，新赛事会完整保存。
- 队名支持 1–24 个字符，在选秀、备战或结果页修改并自动保存；赛事记录保留参赛时的队名，后续改名不改写历史。
- 冠军结果、最终排名与生涯记录使用对应届次的冠军盾原图。`assets/aegis/` 共 14 张图片覆盖全部 15 届，TI1 / TI2 共用早期款，其余各届独立，无缺失；图像来自 [The International Gallery](https://liquipedia.net/dota2/The_International/Gallery)，来源、年度映射与 SHA-256 见 `assets/aegis/sources.json`。
- 逐局战报展示双方英雄头像、中文名、英文定位和选手名。新赛果保存双方阵容快照；旧赛果使用该届六席存档和对应年份的对手名单，后续换人不会改写历史选手。
- 文字卡图鉴支持选手/教练/别名搜索，赛事、位置、战队筛选；按赛事展示八强名单与教练记录。
- 当前版本使用 `dota2myteam.run.v4`，不读取或迁移旧版存档。

## 数据与模型边界

历史事实和游戏参数分开保存。名单和名次以当届资料为依据，账号来自公开身份映射和该届比赛。早期记录不一定具有完整的现代位置划分，因此 1—5 为本游戏固定席位，不代表逐局分路。教练未记载表示未收录，不能据此推断该队没有教练。

模拟使用统一的跨时期英雄池，不逐届还原补丁。英雄的发育、节奏、推进、控制、保护向量为设计参数；30 名英雄沿用手工参数，其余由公开角色标签映射。选手 KDA、GPM、XPM、参战率在同届同位置内标准化，按有效样本数收缩，缺失统计使用中性值。教练适配对比同届八强的英雄组合，避免所有教练因控制类英雄权重偏高而被判成相同打法。

BP 统一使用现代队长模式 **24 手（14 Ban + 10 Pick）**，双方各禁 7 个、选 5 个英雄，分六个阶段交错执行。F 为先选方、S 为后选方：Ban `F F S S F S S` → Pick `F S` → Ban `F F S` → Pick `S F F S S F` → Ban `F S F S` → Pick `F S`。顺序依据 Valve [7.34](https://www.dota2.com/patches/7.34) 与 [7.40](https://www.dota2.com/patches/7.40)，不表示各届早期 TI 都采用这一规则。战报逐手展示阶段、双方、英雄头像和中文名；旧的四 Ban 记录标明旧版，不补造动作。

1—5 号位分别维护位置英雄池，每名选手使用当届完整英雄记录作为个人池（不只 Top 3）；当届记录缺失时才参考本人已收录的选手生涯，教练身份不参与。每个席位的候选严格等于两个池子的并集，个人池中不属于当前位置的英雄也可入选；两个池子都不包含的英雄不能出场。没有个人记录时，并集退化为位置池。每次禁用和选取前检查剩余席位能否分配到互不重复的合法英雄，出场英雄始终来自自身并集。

排除已禁、已选及会导致后续无法完成 BP 的候选后，若交集与并集其余部分均非空，95% 概率从交集选取、5% 从其余部分选取。概率按组分配，避免较大的位置池稀释单个交集英雄的优先级；仅一组可用时全从该组选择。组内用个人熟练度、教练熟悉度及战术适配进行加权随机，所有合法候选权重为正。禁用优先针对对手可用英雄池，即使没有教练记录也执行。教练影响禁用优先级和英雄选择，这些是可重复的游戏规则，不是对教练真实战术或能力的评定。对局生成经济、团战、九座线路塔和基地事件，基地归零决定胜负；未模拟装备、技能、买活或 Roshan。结果未做真实比赛预测校准。

## 当届真实成绩的微弱影响

仅当战队身份、年份与五名选手卡全部匹配当届历史名单时启用，读取 `pool.finish`。自建队、混编队、其他年份的同队以及缺失数据均为 0；队名和教练荣誉不产生加成。每届重新读取真实名次，模拟战绩不回写原始数据。

- 并列取平均名次：5–6 为 5.5，7–8 为 7.5。
- 成绩分 `s = clamp((7.5 − 平均名次) / 6.5, 0, 1)`。
- 对抗实力加成 `0.05 × s`：冠军 0.0500、亚军 0.0423、季军 0.0346、第四 0.0269、第五至六 0.0154、第七至八 0。
- 加到现有每次交锋的实力项上，其余过程不变。同一局面下，单次交锋概率的直接变化最多 `0.05 × 0.14 = 0.007`，即 0.7 个百分点；这不是整局最终胜率的固定加成。
- 该项是用户要求的历史卡牌游戏规则，使用赛事结束后的真实名次，不作为赛前预测特征或训练、校准数据。BP 不受此项影响。每局保存双方实际使用的成绩分与加成，规则版本升至 8。

本次发布继续使用现有比赛算法。未通过验证的模型研究已保存在本地分支 `codex/model-research-20260923`（含用户重写的 `match.md`、模型工件、证据和验证报告），没有合入生产，也没有用手工加成宣称其验收通过。
