# Dota 2 MyTeam

五位传奇，一位名帅。可离线运行的 Dota 2 历史选秀与生涯游戏。

在线游玩：[dota2-myteam.vercel.app](https://dota2-myteam.vercel.app/)

## 运行

```sh
cd /Users/test/Documents/ForFun/Dota2MyTeam
python3 -m http.server 8930 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8930/>。也可直接打开 `index.html`；不同协议、端口和浏览器的存档互不共享。无需安装依赖，没有运行时 API 请求，没有选手头像。

## 当前版本

- 首页采用 Dota 2 官网英雄群像与官方标识，提供已有生涯的继续入口、历史卡库概览、可查看真实资料的跨时代示例阵容，以及三步玩法说明。官方素材本地保存在 `assets/brand/`，来源和 SHA-256 见 `assets/brand/sources.json`；页脚注明非盈利个人项目及 Valve 素材归属。
- TI1 / 2011 至 TI15 / 2026：15 届、120 个历史八强战队池，600 张选手卡、48 张 TI10—TI15 八强代表教练卡。2020 年无赛事。
- 五名选手分别占 1—5 号位；之后进入必选教练轮，只抽年份，展示TI10—TI15 当届八强的八位代表教练，直接选一人。每队仅保留一张教练卡，多人教练组不额外占席。跨年份、改名和选手/教练身份共享人物标识，不能一人占两席。
- 选手轮只提供一个重抽按钮，一次同时更换年份和战队，保证两项都与当前不同；整段生涯共 3 次，选秀和休赛期换人共用。旧存档按两类重抽已消耗次数的总和折算剩余额度，最低为 0，不重置生涯。教练轮有独立的一次年份重抽，不抽战队，不消耗选手额度。教练年份固定为 2021—2026，每届八张；同一人物与已有选手冲突时仍禁选。
- 抽签使用多个候选项连续滚动并逐渐减速，选手抽签 1 秒、教练抽签 0.8 秒。选手的年份与战队在同一个框内成对滚动，每一帧都来自真实的当届战队池，整体减速并同时揭晓两项；教练只滚年份。名单、人数、名次等结果信息在结束前隐藏。结果先保存，跳过动画不重抽；系统启用减少动态效果时使用 150 毫秒等待提示。
- 手机端采用底部导航，选秀阵容默认收起、可随时展开；选人后自动回到下一轮抽签，换人时保留全部席位。按钮扩大触控区域，备战与图鉴在窄屏使用单列卡片；战报以英雄头像、中文名、选手和定位逐行展示，弹窗支持独立滚动、固定关闭按钮和安全区留白。
- 560 张 TI2—TI2026 选手卡接入 OpenDota 逐场统计和真实英雄使用次数。TI1 的 40 张卡保留名单，明确显示统计未收录，不填假数值。
- 组队后只需确认阵容和生涯起点，不再提供风格或英雄选择。战队风格自动跟随所选教练，换教练、进入下一届、恢复旧存档均同步更新；历史结果不改写。自动 BP 参考选手与教练的历史英雄使用及战术；选手 Top 3 英雄头像、中文名、局数和资料详情保留。旧存档的手动偏好移除，阵容、生涯和已完成战报保留。
- 选手 Top 3 常用英雄展示英雄头像、中文名与使用局数，覆盖选秀、备战和图鉴；详情也保留英雄头像。选手本人不使用头像。英雄图片缓存于 `assets/heroes/`，来源记录在 `sources.json`，可用 `python3 scripts/fetch-assets.py` 补齐。
- 执教生涯统计按同一人物的全部已收录 TI 八强教练条目汇总，按历史战队池去重，仅计教练身份。局数和胜率来自该队该届可用比赛样本，胜率为总胜场 ÷ 总局数，不平均各届百分比；没有逐场数据的记录只参与名次统计。最高成绩取最好名次并统计次数，如“冠军 × 2”“亚军 × 2”；详情可核对逐届记录和来源。不包含选手经历、未收录 TI 战队或其他赛事。
- 教练参考执教战队的历史英雄使用，影响针对性禁用、选英雄和战术适配。教练卡不再展示常用英雄，改为擅长风格、历史胜率、历史局数、最高成绩及次数；风格仍是当届执教样本生成的游戏设定。
- 任意一届起步，连续最多十届，在 TI2026 截止。每届结束可随机抽签换一名选手或教练，下一届生效。换教练从阵容的教练席进入，沿用TI10—TI15 年份与八强直选规则，该次换教练可独立重抽年份一次；取消、切换选手位置、刷新均保留年份及已消耗次数。已完成赛果保留当时六席。
- MyTeam 与当届八强共九队：单循环 BO2、前八双败、决赛 BO5。提供排名、完整对阵、逐局 BP 与推进事件。采用自定义赛制。
- 逐局战报展示双方英雄头像、中文名、英文定位和选手名。新赛果保存双方阵容快照；旧赛果使用该届六席存档和对应年份的对手名单，后续换人不会改写历史选手。
- 文字卡图鉴支持选手/教练/别名搜索，赛事、位置、战队筛选；按赛事展示八强名单与教练记录。
- 当前版本使用 `dota2myteam.run.v3`，不读取或迁移旧版存档。
- 教练池筛选清单、多人组代表选择和资料修正见 `data/coach-selection.json`。TI14 Xtreme Gaming 教练已修正为 xiao8；教练卡统计仍使用已收录的跨届执教经历，包含 TI10 之前的有效记录，不因缩小可选卡池丢失历史荣誉。

## 数据与模型边界

历史事实和游戏参数分开保存。名单和名次以当届资料为依据，账号来自公开身份映射和该届比赛。早期记录不一定具有完整的现代位置划分，因此 1—5 为本游戏固定席位，不代表逐局分路。教练未记载表示未收录，不能据此推断该队没有教练。

模拟使用统一的跨时期英雄池，不逐届还原补丁。英雄的发育、节奏、推进、控制、保护向量为设计参数；30 名英雄沿用手工参数，其余由公开角色标签映射。选手 KDA、GPM、XPM、参战率在同届同位置内标准化，按有效样本数收缩，缺失统计使用中性值。教练适配对比同届八强的英雄组合，避免所有教练因控制类英雄权重偏高而被判成相同打法。

BP 合计四禁、十个不重复英雄。教练用对手常用英雄作禁用参考，其原战队常用英雄得到选取倾向；这些是可重复的游戏规则，不是对教练真实战术或能力的评定。对局生成经济、团战、九座线路塔和基地事件，基地归零决定胜负；未模拟装备、技能、买活或 Roshan。结果未做真实比赛预测校准。

## 开发入口

| 文件 | 职责 |
| --- | --- |
| `index.html` / `styles.css` / `home.css` / `mobile.css` / `script.js` | 首页、英雄头像与选手文字卡、响应式布局、交互及浏览器存档 |
| `data/coach-selection.json` | TI10—TI15 每队一名代表教练、核对来源和修正记录 |
| `data/rosters.tsv` | 各届八强、历史队名、五个游戏席位、记录中的教练 |
| `data/people.json` / `data/person-aliases.json` | 账号绑定及人物别名 |
| `data/events/` | 14 届 OpenDota 查询、原始快照、获取时间与 SHA-256 |
| `data/research/heroes-zh.json` | Valve 官方简体中文英雄名称快照，附来源与 SHA-256 |
| `scripts/import-events.py` | 获取缺失的公开快照；已有文件不覆盖 |
| `scripts/build-catalog.py` | 校验账号/战队/快照哈希，离线重建完整卡库 |
| `catalog-data.js` | 自动生成的完整历史数据包 |
| `data.js` | 运行时索引、英雄参数、统计标准化和教练适配 |
| `game.js` | 六席选秀、BP、模拟、换人、生涯及存档校验 |
| `tests/` | 关键业务规则及统计聚合验证 |

`stats-data.js`、`data/raw/`、`data/accounts.json` 与 `scripts/build-stats.py` 保留为旧两届版本资料；新版入口只加载 `catalog-data.js`。完整统计口径、来源和重建流程见 [data/README.md](data/README.md)。
